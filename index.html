Content Engine

A private, single-operator tool for producing and publishing original video content.

Content Engine is a personal tool built and operated by Dileep Kumar Pothala. It automates one person's own video production pipeline: it generates original scripts, produces original narration and motion-graphic visuals, renders the finished video locally, and uploads it to YouTube channels that the operator owns and operates.

It is not a public product. There is no sign-up, no web interface, and no users other than the operator.

Channels it publishes to

  • Vice Signal — gaming news, lore, and commentary
  • Sing & Sprout — gentle songs and early learning for ages 2–5

Google API use

The tool uses the YouTube Data API v3 to upload videos to the operator's own channels and set their metadata, and the YouTube Analytics API to read back performance data for those same videos. It does not access private user data belonging to anyone else.

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
