Privacy Policy

Last updated: 16 August 2026

What this is

Content Engine is a personal, single-operator tool used by Dileep Kumar to publish videos to YouTube channels that Dileep Kumar owns and operates. It is not a public product, has no other users, and offers no sign-up.

Data it accesses

The tool uses the YouTube Data API and YouTube Analytics API with credentials authorized by the channel owner. It accesses:

  • Video metadata for videos it has itself uploaded (title, description, tags, status)
  • Aggregate analytics for those videos (views, watch time, impressions, click-through rate, subscribers gained)
  • Public metadata of other YouTube channels and videos for research purposes (titles, view counts, publish dates)

It does not access, download, or store: viewer personal information, comment author identities, private user data of any kind, or video or audio content belonging to other creators.

How data is stored

All data is stored locally in a Microsoft SQL Server database on a personal computer under the operator's sole control. Nothing is transmitted to any third party, sold, shared, or used for advertising. No data is stored outside the operator's own machine.

Retention and deletion

Data is retained for as long as it is useful for operating the channels and may be deleted at any time by the operator. Authorization can be revoked at any time from the Google Account permissions page at https://myaccount.google.com/permissions, which immediately ends the tool's access.

Google API Services

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
